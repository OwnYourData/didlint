Universal Resolver

Resolves a decentralized identifier (DID) to its DID document, for the methods listed below. An instance of the Universal Resolver of the Decentralized Identity Foundation, operated by OwnYourData.

Examples are loaded from the resolver.

Check with DID Linter API request

DIF marks the methods the Decentralized Identity Foundation recommends. Other methods are not forwarded to another resolver.

API

The API of the Universal Resolver, without authentication:

curl https://uniresolver.ownyourdata.eu/1.0/identifiers/did:web:danubetech.com
curl -H 'Accept: application/did-resolution' https://uniresolver.ownyourdata.eu/1.0/identifiers/did:web:danubetech.com
GET /1.0/identifiers/{did}resolve a DID; with Accept: application/did-resolution the full resolution result with metadata
GET /1.0/methodsthe supported methods
GET /1.0/testIdentifiersexample DIDs per method
GET /1.0/propertiesconfiguration of the drivers

The instance answers at most 300 requests per minute in total. Each requested DID and its result are written to the log of the service. Drivers, images and configuration are described in the repository.
